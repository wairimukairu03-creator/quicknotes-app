# Quicknotes Web Application

A lightweight, responsive browser-based note-taking application that categorizes notes and saves structural logs securely locally within user devices.

## Features

- Dynamic addition and removal of items.
- Real-time filtered text querying across all records.
- Strict evaluation logic restricting character overhead limits.
- Persisted data storage configuration active throughout active tab cycles.

## How to Run Locally

1. Clone or download this project source folder locally.
2. Locate the root folder directory path.
3. Open `index.html` inside any standard web browser.
